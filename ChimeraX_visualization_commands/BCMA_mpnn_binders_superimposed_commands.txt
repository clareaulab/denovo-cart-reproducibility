# After loading all PDBs (Make sure parental is the first one loaded)

## Align on chain B (BCMA)
mm #2-25/B to #1/B

## Hide BCMA for all but the first PDB
hide #2-25/B cartoon

## Makes it gray
color #1/B gray

## Show the surface
show #1/B surface

## Make it transparent
transparency #1/B 70

## Graph the outline of(silhouette)
graphics silhouettes true

## Use the soft lighting mode
lighting soft

## Making sure shadows are off
lighting shadows false

## Make sure the background is white
set bgColor white

### To show the interface residues 
hide #2-26 cartoon

## Make color consistent with the color from another figure
color #1/A teal

### select the interface residues
select #1/A:12 #1/A:13 #1/A:16 #1/A:17 #1/A:20 #1/A:23 #1/A:24 #1/A:30 #1/A:31 #1/A:37 #1/A:40 #1/A:41 #1/A:44 #1/A:45 #1/A:47 #1/A:48 #1/A:51 #1/A:52 #1/A:55

show sel atoms
